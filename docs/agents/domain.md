# Domain Docs

This repository uses a single domain context.

Before exploring or changing the codebase:

- Read the root `CONTEXT.md` and use its canonical language.
- Read relevant architectural decisions under `docs/adr/`.
- Surface any proposed change that contradicts an existing ADR instead of silently overriding it.

`CONTEXT.md` is only a glossary. Implementation decisions belong in ADRs or feature specifications.

# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues at `hnewcity/KiroaaS`. Use the `gh` CLI from this clone so the remote determines the repository.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- Apply or remove labels with `gh issue edit`.
- Close completed or rejected work with `gh issue close` and an explanatory comment.

## Pull requests as a triage surface

Pull requests are not a request or triage surface.

## Publishing

When a skill says to publish a spec or ticket to the issue tracker, create a GitHub issue in `hnewcity/KiroaaS`.
